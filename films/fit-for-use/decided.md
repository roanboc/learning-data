# Decided: Fit for use

The module's decisions, and this series' own. The module's other series keeps its own in its folder (`../quality-as-a-habit/`). With each film's rows (`<n-film>/decided.md`), they make the *Decided* table in [proposal.md](proposal.md): run `python site-tools/build_series.py` after adding a row. A decision a film's thread makes, even one for the whole module, goes in that film's file, so threads never edit the same lines.
