# Choose the skill

This skill's only job is to choose. Each of the project's seven skills has a name and a
description, and the description's last sentence says when to use it. Read those, not the
skills' steps: load the steps of the one that fits, and only that one.

## Steps

1. **Say the job in one sentence**: what you were asked to do, to what, and for whom. "Check
   Jun's change before Noor signs it off" is a job; "look at the data" isn't one yet: ask.
2. **Read each skill's description** in `skills/*/SKILL.md`, and compare the job with the
   sentence that says when to use it. Don't keep a copy of those sentences here or anywhere
   else: the skill's own file is where each one lives.
3. **Load the one that fits**, and follow its steps. If two fit, the job is two jobs: do them one
   at a time, each with its own skill, and say so.
4. **When no skill fits, don't guess**, and don't stretch one that almost fits: its steps were
   earned on another job. Say so, and ask the person you work with to do the job first.

## When no skill fits

A job no skill fits is done by hand first, by a person, who writes down each step as they go.
If the job comes back, those notes become the next skill: a file `skills/<name>/SKILL.md` with
a name, a description whose last sentence says when to use it, the steps, and, as they're met,
the cases met so far and how each was settled. It's reviewed in a pull request like any change,
and added to the list in `AGENTS.md`.
