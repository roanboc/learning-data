# Portal

The source and the columns only it holds. Each is described once, here, and shown with `doc()`.

{% docs source_portal %}
The student portal: where students and graduates do their own business with the university. When
a graduate registers for a ceremony, it shows their name as it would be printed on the certificate
and asks them to confirm it or correct it; the registrar's office checks each correction before
it's accepted. Key set `SP`. Its answers come to the platform on their own, every night, with every
letter kept. Every version of every row is kept; see the version columns in
`models/_shared/_shared__columns.md`.
{% enddocs %}
