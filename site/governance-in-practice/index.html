The films

Watch them in order: each film builds on the one before.

  1. 1Governed in dbt7 min · Owners, classes, contracts and decisions kept beside the code in dbt, and checks that hold every pull request to them.
  2. 2Governed in Unity Catalog6 min · Tags from the project's classes, one policy that masks, groups with end dates, and a log of who read what.
  3. 3Meaning on the platform6 min · One page for each term, copies checked against it, and a count defined once, so people, reports and agents get one number.
  4. 4Quality on the platform6½ min · Tests with an owner and a level, checks where data is typed and loaded, monitoring for the rest, and one scorecard.
  5. 5Products in open formats6½ min · Product files written by their owners, core tables' contracts written first by data governance, a check on every change, and open standards.
  6. 6The marketplace6½ min · A catalogue of products, requests with a purpose and an end date, the owner's yes, and sharing outside without copies.
