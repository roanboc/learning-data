Context and memory, governed like any data

Lucía, new in Planning, asks her agent how many students the library should buy e-books for. It says 18,026, leaving out 386 who study online: a line in the team's memory had lost three words. So the team governs its context and memory like any data, with an owner, a review and a way to delete.
