Para el cómo: las fuentes oficiales

Las películas se quedan con las ideas. La documentación y la formación de cada herramienta las mantienen al día quienes la construyen: empieza ahí, y luego prueba lo nuevo sobre una necesidad real.

  • Documentación de Databricks (en inglés)Databricks: qué hace cada función, cuánto cuesta y dónde se detiene.
  • Notas de versión de Databricks (en inglés)Databricks: qué cambió este mes, para elegir qué vale la pena probar.
  • Formación de Databricks (en inglés)Databricks: cursos y rutas de aprendizaje, de quienes lo construyen.
  • Documentación de dbt (en inglés)dbt: modelos, pruebas y publicaciones, como los usa el proyecto de datos.
  • dbt Learn (en inglés)dbt: cursos gratuitos, del primer modelo a publicaciones probadas.
