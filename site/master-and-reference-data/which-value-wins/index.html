Which value wins: a rule for each field, declared in one place, not hidden in the code

In 1831, HMS Beagle sailed with twenty-two clocks, and which ones to trust was decided before they could disagree. At the university, Linh's five records are now linked to one person, and their values still disagree: four ways of writing her name, two birth dates, two mobile numbers, four emails. The model already picks one, with a single order for every field, hidden in the code, and letting the newest value win would hand her record to HR's resent file, typo and all. Jun writes a rule for each field in one place, where the steps that build her record read them: on a master data tool's screens or, in the simplest form, in a file. Mei pins the right birth date with a reason, and every value keeps its source, its rule and its age.
