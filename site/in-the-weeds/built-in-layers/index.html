Built in layers: one job per layer, one step per CTE

The tests are written, and they wait for code. Like the stations of Escoffier's kitchen, each layer of Jun's project does one job: staging tidies a table, intermediate holds the steps, the core holds what the blueprint names, and each mart serves one consumer. Inside a model, each CTE is one step.
