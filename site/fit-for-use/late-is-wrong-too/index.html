Late is wrong too: one list, three clocks

On Wednesday night, 17 June 2026, the student system's nightly file didn't come. The graduation list was built from the night before's: every check green, and 23 graduates missing. Malia Fonoti, Sam Okafor and Mei Tanaka agree how fresh each use needs it, and the list starts saying its age.

  • Anomaly detectionHow Databricks learns when each table usually arrives, and shows which are late, as Sam saw that Thursday.
