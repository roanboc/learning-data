| 11 | Does the rule of 12 November 2026 on what an agent reads in production hold here? | Yes, as I read it. AGENTS.md now says an agent in production reads with limited access, "personal and sensitive data masked", never closed out and never reading unmasked personal data. That rule reached main while this film was being made, for the agents that work on the data team's pipelines. The chat is stricter: its own identity reads no personal data at all, and nothing sensitive, masked or not, because its place holds only public and internal products. It reads a household's own account only on that household's sign-in, as the website does, which I read as the household's own access, not the agent's.
