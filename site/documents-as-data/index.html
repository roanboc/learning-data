One thread: an invoice, from a file to a tested feature

Finance receives about 3,860 supplier invoices a month, most of them as PDF files, and HR keeps every contract its staff sign, Linh Nguyen's among them. Files as data and as context reads them as data, with the platform's functions, into tables Finance can check, and keeps each file and its metadata as context an agent may cite. Ideas that last, features you test shows how that came about: Rohan's team asked for a better way, and Jun tried the functions on 200 invoices in two days before building one use case properly.
