Every name was allowed, and 88 were still wrong

In February 2026, every name on the March graduation list passed the checks that say a name is allowed. Asked in the portal, the graduates corrected 88 of them, and a check against the exam boards' approved lists found two awards missing. Only a reference outside the data says what's true.
