Memory: let every agent learn from every chat

In April, Jun's agent counted 37 students short on census day, and learned why in one chat. In June, Clara's agent made the same mistake, and her budget figures nearly went out short. So the team keeps such lessons in one memory every agent reads: each approved by a person, with no names.
