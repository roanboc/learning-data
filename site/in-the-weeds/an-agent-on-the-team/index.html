An agent on the team: it drafts and checks, with evidence; people approve

An AI agent can read a dbt project, run it and draft a change in minutes. To be trusted, it needs what a new colleague needs, written down: rules, skills and who approves each step. Least access, a query behind every claim, a test it never weakens, and a reconciliation, a diff and CI before people sign off.
