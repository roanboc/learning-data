Context engineering: what an agent reads, and who writes it

Planning asks how many of the 18,412 students on census day were commencing. Nothing Jun's agent reads says what the word means, so it guesses from the names and counts 6,931. Mei knows: a student back from leave isn't new. She writes the meaning down once, and the agent counts 6,212.
