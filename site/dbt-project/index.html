The example dbt project

One real dbt project, for a fictional university, is behind many of these films. Every file they show on screen is in it. It runs on your laptop with DuckDB, and the same code runs on Databricks.

Open it on GitHubHow to run it

What it is

It started with one question from Planning: how many learners are within 15 credit points of a graduate certificate, by faculty, at census date? In the weeds of data crafting builds that answer step by step. Later films add what a real team needs around it: a wallet app and Finance reading the same facts, payroll's jobs, data quality checks, governance files, and the rules AI agents work under.

Run it yourself

On your laptop

Python 3.11 or later, no account. dbt loads the sample data, builds every model and runs every test, on DuckDB.

cd films/analytics-engineering/project
pip install -r requirements.txt
dbt build --profiles-dir .

On Databricks

The same code, with dbt Cloud or dbt Core. Load the sample files into Unity Catalog first; the README has the steps.

pip install -r requirements-databricks.txt
dbt build --target databricks --profiles-dir .

How to run it

Where things live

The main folders, and what each holds. Each link opens it on GitHub.

  • models/What's built, by domain: staging, the core tables every team shares, and the marts each team reads.
  • sources/What comes in from the three systems: tables, keys, freshness and known limits.
  • seeds/Reference data the business owns, and published numbers to reconcile against.
  • tests/Business rules that must hold, reconciliations, and rules about the project itself.
  • macros/Conventions written once: keys, point in time, Planning's rule, and Databricks tags and masks.
  • analyses/The evidence: profiling the sources, a design choice, and checking the result.
  • exposures/Who uses each output: dashboards, apps, forecasts and agents.
  • governance/The glossary, owners, the architecture map, data products, contracts and agents' mandates.
  • docs/How the work is done: the process, conventions, decisions and the quality scorecard.
  • AGENTS.md skills/What an AI agent may and may not do here, and the skills it uses.
  • examples/Pull requests, nights and Databricks set-ups that the films tell as stories.
  • databricks.yml resources/The jobs, deployed as one bundle to test and to production.
