# Data architecture: the series' own questions and assumptions

*Enterprise architecture* · *Data architecture*, its labs and scenarios, for all six films · PR #382 · [pull request](https://github.com/roanboc/learning-data/pull/382)

[Take it apart](https://data.learn-all.org/data-architecture/labs/) · [Make the call](https://data.learn-all.org/data-architecture/scenarios/)

The series' pack of labs and scenarios, made on 12 November 2026 after its six films reached main. The plan the author confirmed on 11 November (pull request #318) names only one lab for these series, *Model the data practice*, for the platform series' consolidated view; this pack is the film thread's own addition, so each film's page leads to more than its Pause and think questions, as *The map before the data*'s do. Every question below would have gone to the author, and was answered instead with the best-reasoned option, for him to confirm or correct.
