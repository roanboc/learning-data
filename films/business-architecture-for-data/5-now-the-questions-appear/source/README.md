# Rebuilding Now the questions appear

*Now the questions appear*, film 5 of 7 of *Business architecture for data*, is generated from code like *The map before the data*: the same engine, components, voice and tools (`films/enterprise-architecture/shared/tools/`, which run From words to data's), with the series' own components in [`../../shared/src/ba.js`](../../shared/src/ba.js), among them the qanat's section and its windlass. It was film 8 of *The map before the data* until 23 November 2026, and its present-day chapters use that series' components as they are. Its own glyphs for a decision, a question, a measure and a data product (`d8_glyph`) live with its pictures. Only what is new lives here:

## Rebuild

As for [*Processes, as deep as data needs*](../../4-processes-as-deep-as-data-needs/source/README.md#rebuild), from this folder, `films/business-architecture-for-data/5-now-the-questions-appear/source/`; the video is `dist/now-the-questions-appear.mp4`.

## Publish

`python tools/publish.py` copies the player, the soundtrack and the Spanish captions to `site/assets/now-the-questions-appear/` and draws the poster; then `python site-tools/tiles.py` cuts its tile and `python site-tools/build_series.py` makes the pages. "Pause and think" is `site/assets/now-the-questions-appear/think.en.js` and `think.es.js`: it stops after `up`, `count` and `build`. Progress is stored under `ld-now-the-questions-appear`. The soundtrack's pointer is `../audio.json` (`python site-tools/media.py index --film now-the-questions-appear-en`).
