Reglas que se ejecutan: medir la calidad con lo que se ejecutó

La política de la universidad dice que la calidad de datos se monitorea, pero monitorear significa una encuesta anual sobre cómo se siente cada dueño con sus datos. Y el equipo de datos ya ejecuta 160 controles cada noche. Yusuf le da a cada control un dueño y una dimensión, cada dueño fija su nivel, y el tablero se lee de lo que se ejecutó.
