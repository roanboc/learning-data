Kept alive: a map stays true only while keeping it is someone's job

A year on, every check on the utility's map passes, yet a crew's assistant gives four steps where there are five, and a retired owner's name is still on thirty elements. Tomás makes keeping the map a job: an owner, a budget and a rhythm, and agents that read the map itself, never a copy.
