Go further in the official docs

The film gives the practice and leaves the depth to the official docs and standards, which stay up to date as the tools change. Checked on 10 November 2026.

  • Keep what a check holds: dbt's store_failuresdbt saves the rows a check finds in a table of their own, which the owner's team can read, as the registrar's office reads the names Jun's check holds.
  • Hold or stop: dbt's severityA check that warns holds its rows for a person; one that errors stops what's built after it.
  • Databricks SQL alertsA query run on a schedule, and a message when its result meets a condition, as the registrar's office hears each morning which reports are due.
  • The Open Data Contract StandardWhere a contract says how to report a problem with the data: its support channels, such as the portal's "This isn't my name".
  • dbt's data testsA check is a query that finds the rows that break a rule: here, a name the old form made, not yet confirmed.
