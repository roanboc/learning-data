Datos como software

La segunda serie de Lo básico de los datos modernos. La exportación de nómina a Finanzas corrió años como un script en el portátil de una persona. Dos películas: el trabajo con datos llevado como software, versionado, revisado, probado y desplegado, que no es nuevo; y una plataforma que vigila sus tareas y propone un arreglo que aprueba una persona.

Un hilo: la exportación de nómina, de script a software

Cada dos jueves, las cifras de nómina llegan a Finanzas por una exportación que corrió años como un script en el portátil de una persona. Sam Okafor y Jun Park la llevan al proyecto de datos, donde se versiona, se revisa, se prueba y se despliega igual cada vez. Luego, una noche, falla la tarea que carga las horas aprobadas, y la plataforma encuentra la causa y propone un arreglo, que Sam revisa antes del día de pago.
