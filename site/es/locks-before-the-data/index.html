Cerraduras antes que los datos

La primera serie de Protección de datos y privacidad. Un proceso nocturno carga los datos del registro con el token personal de Jun, desde un espacio de trabajo abierto a internet. Cuatro películas muestran las ideas detrás de las cerraduras de una plataforma, sin nombrar productos; cinco las construyen en Databricks, GitHub y Azure.

Un hilo: un proceso nocturno, de un token prestado a un nombre propio

El proceso que carga cada noche los datos del registro se ejecuta con el token personal de Jun Park, creado en 2024 sin fecha de fin, desde un espacio de trabajo abierto a internet. Película a película, Sam Okafor le da un nombre propio y ningún secreto que alguien guarde, pone el espacio de trabajo tras caminos privados, lleva el gran poder de los especialistas a cuentas de administrador que se encienden para una tarea, deja que producción cambie solo con revisión, y lo vigila todo.
