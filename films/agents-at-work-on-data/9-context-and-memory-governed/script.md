## The promise

Every line passes two tests: someone who has only heard of AI agents can follow it, and a data governance lead and a platform engineer who runs agents on Databricks each find nothing wrong in it. The series began with what an agent reads (*Context engineering*), and this last film closes the circle: what an agent reads shapes what it does, so it is data, and gets what any data gets: an owner, who may read it and who may change it, a review before agents use it, a time to keep it, and a way to delete it everywhere it's kept. The team's context answers all five: it lives in the team's repository on GitHub, reviewed like code, its definitions copied from the business glossary on Databricks, and it goes one way to where agents read it. Memory answers four: the platform keeps it, in Lakebase, and a daily step keeps hundreds of lines a week with nobody approving each, more than anyone could read or keep up to date. So the team sets an order: what agents must get right, the glossary's definitions and the data rules, each with an owner who reviews every change, comes first; memory comes second, and where a line disagrees with a definition, the agent follows the definition and flags the line to the memory's owner. Governing the definitions is what makes it safe to let the platform keep the memory: a line can be wrong, and still can't change an answer. The film is about the order in which agents read; what an agent reads is *Context engineering*'s, how a lesson becomes the team's is *Memory: from one chat to the team*'s, and an agent's own identity and rights on the platform are *Why Unity Catalog and Unity Gateway govern them*'s. **Govern what agents must get right. Memory comes second.**

## The story in one paragraph

Today, at the university: Lucía Ortega joined the Planning team on Monday. Her agent starts each day with the team's memory: what its agents learned in their sessions, kept by the platform. Her first job is for the library: which units run next semester, so it can buy their e-books? Her agent lists 1,142, and a plain check against the student system, which lists 1,236, stops it. The 94 it left out are all taught only online, so the library would have bought no e-books for them, though their students are the very ones who can't come in for a book. The agent's evidence shows why: one line in the team's memory, "Count only units taught on campus". The platform kept it in July as "For room bookings, count only units taught on campus", right for rooms; since last week it had lost the three words that made it right, and nobody saw it change. Yet the glossary already said what a unit offering is: a unit taught in a semester, on campus, online or both. Nothing told the agent which comes first. So the team sets an order: first what's governed, the glossary's definitions and the data rules, each with an owner who reviews every change; second, memory, which the platform keeps, with nobody approving each line. When the two disagree, the definition wins, and the agent flags the line. Now Lucía's agent lists all 1,236 units and says which definition it followed, and the library buys e-books for every one. The film then goes back over what an agent reads, the series' four kinds of context and memory, and the five questions any data must answer, which the team's context answers in full and memory, unreviewed line by line, in part; the team's context, kept on GitHub and reviewed like code, its definitions copied from the glossary with their source, going one way to Unity Catalog and Unity Gateway, where nobody edits it; its memory, in stores in Lakebase, where a daily step merged the campus line with another line about counting units, as it's built to, in a store where whoever may write may change any entry and nothing records what it said before; approving each line by hand, which works for a few, and the hundreds a week the step keeps; the order again, the definition winning over the line; Yusuf in data governance owning the memory as a whole, who may read and write each store and how long it's kept, deleting each flagged line that's wrong; and the team's store, which every agent may read and only the step writes. Keeping and deleting are decisions too: sessions kept thirty days; deleting has traps, since deleting a chat deletes nothing of what was kept from it and the skill sync never deletes, so the team deletes where a thing is kept, and Yusuf records it. Asked again, Lucía's agent lists all 1,236 with its evidence and the definition it followed, and the series closes on its nine lessons and the road ahead: *From helper to colleague*.
