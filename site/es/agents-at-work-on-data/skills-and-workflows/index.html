Skills y flujos de trabajo: resolver una vez, reutilizar

Cada vez que el equipo de Jun conciliaba el conteo del día del censo, el agente empezaba de cero: las causas ya halladas quedaban en un chat, una nota, un correo. Ahora una skill las guarda, un router la elige y un flujo nocturno llama al agente solo si las cifras no coinciden, y decide una persona.
