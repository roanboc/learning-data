Moving is easy, agreeing is the work: at each interface

HR's contracts once reached Finance as a file each teaching period, and Rohan Desai's team spent two days working out what each column meant. Now a connector, a query in place and a mirror move them with little work. What's left is the contract Ingrid Holm and Noor Rahman agree.
