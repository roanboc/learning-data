# How to meet governance's rules

The governance check (`scripts/check/governance.py`) runs on every pull request. When it stops you, its message links one of these pages. Each says what the rule asks, why, how to fix it in three steps, and who to ask.

| The message starts with | Page |
|---|---|
| `owner:` | [Add an owner](add-an-owner.md) |
| `glossary:` | [Name the glossary term](name-the-glossary-term.md) |
| `columns:` | [Classify a column](classify-a-column.md) |
| `tests:` | [Give a test an owner and a dimension](give-a-test-an-owner.md) |
| `described:` | [Describe a column](describe-a-column.md) |

A message that starts with `warning:` is a new rule. It doesn't stop you yet, and it says the day it will (DEC-PRJ-14). Fix it before that day.

**Who to ask.** Data governance's office hours, Thursdays from 2 to 3 pm, or data.governance@uni.example. Bring the message.
