# Enterprise architecture: the four new series' shared questions and assumptions

> Written on 11 November 2026, when the four series that follow *The map before the data* were set up from the proposal the author confirmed that day (pull request [#318](https://github.com/roanboc/learning-data/pull/318)). Each film's own questions and assumptions are in its own file, a folder per series (`<n-series>/<film folder>.md`), written in the film's own pull request.

The four series are *Business architecture for data* (folder `2-`), *Data architecture* (`3-`), *Platform and solution architecture* (`4-`) and *AI and continuous architecture* (`5-`); *The map before the data*, made before this folder existed, is the first. What they share is in [`films/business-architecture-for-data/proposal.md`](../../../films/business-architecture-for-data/proposal.md) and its *Decided* table.
