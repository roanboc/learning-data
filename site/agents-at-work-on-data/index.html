The films

Watch them in order: each film builds on the one before.

  1. 1Context engineering7 min · Jun's agent guesses what a word means and counts 6,931. Written down once by its owner, the meaning gives 6,212, for everyone.
  2. 2Skills and workflows7½ min · A job done once by hand becomes a skill every agent reuses; a nightly workflow calls the agent only when the numbers differ.
  3. 3Tools are hands, and every hand is a permission7½ min · Jun's agent has six tools, its hands. Each gets only what its job needs, so a line hidden in a ticket can't send the list out.
  4. 4Memory: from one chat to the team7½ min · A lesson Jun's agent learned in one chat never reached Clara's. The team's memory, approved by a person, now reaches every agent.
  5. 5Plan, define the check, do, check9 min · Nobody knows the count yet, so Jun decides first what any right answer must meet. When 28 students go missing, a test catches it.
  6. 6How it goes wrong7½ min · Jun's agent works on the census-day count. Six ways it can go wrong, none anyone's fault, and the design the team builds for each.
  7. 7Working with agents on Databricks7½ min · Three agents with their own copies give three answers. On Databricks, with the same data and tools, all three say 168.
  8. 8Why Unity Catalog and Unity Gateway govern them8½ min · Anil's agent read the staff table on his key. Now it has a name of its own, only the grants it needs, and a model it's allowed.
  9. 9Context and memory, governed8½ min · A line in the team's memory lost three words, and Lucía's agent left out 94 units. Now the glossary's definition wins.
