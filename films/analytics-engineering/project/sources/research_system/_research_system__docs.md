# Research system

The source and the columns only it holds. Each is described once, here, and shown with `doc()`.

{% docs source_research_system %}
The research system: the research office's list of research projects and the people on them. Key
set `RES`. Every version of every row is kept; see the version columns in
`models/_shared/_shared__columns.md`. A researcher has one member ID, whatever projects they join;
one who is on the staff also holds their staff ID from HR. Project roles: lead, researcher.
{% enddocs %}
